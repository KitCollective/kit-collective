# Staff can revoke a collector’s Auth sessions

A collector can revoke all of their own Auth sessions from Profil settings. Staff can revoke that collector’s sessions from the Admin drill (stolen phone, support) and their own from the Admin account. Revoke is Identity, not Staff access and not a second IdP. We accept the support/privacy trade-off: an admin can kick devices; they cannot see Peer Profil or invent a second login.

Status: accepted.
