# Kader fetch is the live Transfermarkt path; Apify is opt-in

Coolify’s Hetzner IP gets HTTP 202 and an empty body from Transfermarkt. Apify pay-per-event is too expensive as the backfill engine. Live facts therefore use kader HTML (Cheerio) plus a residential Seed proxy (Decodo). The Store actor stays in the tree as Opt-in Apify — the operator must name it; we do not fail over automatically, because that spends quota Nicklas does not want to spend.

Felipeall is not a dependency. Decodo’s browser Scraping API is not the fetch. Nest still never hits Transfermarkt.

Status: accepted.
