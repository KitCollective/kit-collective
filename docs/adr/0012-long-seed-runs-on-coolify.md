# Long Seed runs execute on Coolify

A Proof run (one season) may run from Cursor MCP on a laptop. A Season range that takes hours (Superliga 1995/96 through 2025/26) is a Coolify job the chat starts, so the walk does not die when the Mac sleeps. ADR-0007 still holds: the human talks in chat; Coolify owns the host and jobs.
