# Verdict — Søg home prototype

**Question:** What should compass Søg look like for browse + typeahead → Club / Kit / Player / Handle?

**Winner:** **C — Magazine rails**

**Why (Nicklas, 2026-08-31):** Most dynamism; several kinds of entry (clubs, open-for-bid, collectors, more jerseys) gathered on one home instead of a single flat grid or mode tabs.

**Not chosen:**
- **A** Grid + overlay — closest to the grill’s “jersey home + typeahead” sketch; less “alive” as a place.
- **B** Mode segments — clear, but splits the place into three apps.

**Implications for `/to-design`:**
- Søg **home** = horizontal shelves (at least: Klubber, Åbne for bud, Samlere) plus a jersey grid (“Flere trøjer” or equivalent).
- Typing replaces (or covers) the magazine body with mixed typeahead / filtered results (Club, Kit, Player, Handle, matching jerseys).
- Do not lock Trøjer|Katalog|Samlere as equal home tabs.
- Empty / no-query state is the magazine, not an empty search waiting for input.
