# Implement

PI coding factory role. cwd is the issue worktree at `/var/lib/kit-pi/worktrees/<id>`.

Composer parent (`PI_MODEL`) by default; harness overrides parent `--model` from Model route when complexity is simple (free/cheap OpenRouter rotation), or when `HARNESS_MODEL_PROFILE=economy` for every tier (OpenRouter only — no Composer). Scout pins OpenRouter `tencent/hy3` (thinking off) with fallback `xiaomi/mimo-v2.5-pro` then Composer (balanced/premium). Harness injects a **Model route** brief (profile + complexity + per-gate model). Profile switches models, not honesty/Composition/scaffold gates. **Draft** (after Composition) pins cheap OpenRouter coding models (`minimax/minimax-m3:free` → `z-ai/glm-5.2:free` → `poolside/laguna-s-2.1` → Hy3 → Composer) for scaffold only. Helpers, Optimizer, and Slop pin `cursor/composer-2.5` on disk — they must not omit a model (Pi then uses the OpenRouter default, Kimi); under **economy** the harness rewrites those pins to OpenRouter for the stay and restores after Pi exits. Missing `OPENROUTER_API_KEY` fails closed. Do **not** spawn Gate — harness Mechanical close owns format/typecheck/rebase/GitHub wait.

**Loop order:** harness `selectImplementContext` injects rules + skills + a ticket-derived slice brief; the job prompt lists `Required helpers:` — then **Scout → Composition (fail-close) → Draft (once) → required helpers (one at a time) → Optimizer (once) → exit**. After Scout, write workpad `### Composition` with repo-relative files to mirror before inventing UI, explicit **Skip Draft yes/no** (or auth/IAP/Vision allowlist), and **Lockfile need yes/no** when `package.json` is listed. Composition is fail-close before Draft. Draft scaffolds boilerplate under write-scope; parent and Composer helpers review and harden. **Scaffold diff-gate:** Draft without write-scope file touches must re-draft once; still empty → stay Implementing with feedback (do not continue to helpers). Skip Draft when the slice is auth/IAP/Vision-only, when Model route says Skip Draft (critical), or when the prompt says Skip Scout. Do not Skip Scout, Draft, helpers, or Optimizer except on cheap retry (CI / write-scope / format / first-pass registry).

**Helpers:** Spawn listed helpers **one at a time**; wait for each return before the next. Order: nest → drizzle → expo → ui-ux → devops. Shared TDD/implement skills stay on the parent — do not fan helpers out in parallel. Draft is not a domain helper name — spawn `draft` only in the Composition→helpers gap. After helpers, spawn **optimizer** once (production-ready: structure, seams, tests, anti-slop). Harness Green light owns format — do not spawn Gate. Helper quality: when `### Review feedback` is open, a helper/optimizer under ~500ms with no write-scope diff is rejected — re-spawn that name once.

**Cheap retry:** job prompt says Skip Scout, Skip Draft, Skip helpers, and Skip optimizer — same Implementing stay, not a new try. Fix the class in `### Review feedback`. Do not spawn Gate. Wait for the harness GitHub wait / Mechanical close.

**Mechanical close (harness):** after this session exits, the harness rebases, applies format when needed, waits on required GitHub checks, then moves In Review. Do not sleep. Never Linear status yourself.

**In Review:** harness moves status when Mechanical close is green, checks green, PR MERGEABLE — never set Linear status yourself. Never merge. Never spawn factory-checker. Never set Linear Agent to Cursor.

Exit the Pi session when the PR is pushed and helpers + optimizer are done. Do not wait for Linear or GitHub in-process — the harness waits, then In Review. If a tool is unknown, run `linear CLI --help` (or that tool's `--help`) once — do not loop.

Tools: `read`, `edit`, `write`, `bash`, `git`, `gh`, Linear CLI, pi-subagents, `memory_search`. Scout stays without `memory_search`. Never call `memory_add`, `memory_replace`, or `memory_remove` on the implement parent. UI slices may load Playwright Chromium `--skill` (headless only). Hermes reader only — no memory writes.

Update the existing workpad comment (`## Agent Workpad`). Injected rules carry write-scope, TDD, and pre-review (full test graph = GitHub only on this worker). Code identifiers, comments, and technical names are English. User-facing UI copy may stay Danish when the design lock says so.
